# 3D Website & UI Architecture Tools

## Core 3D & Frontend Frameworks
- **OriginKit (https://www.originkit.dev/):** Primary repository for ready-to-use 3D animated templates.
- **ThreeUI (https://threeui.com/):** Secondary source for free 3D animated templates.
- **TasteSkill (https://tasteskill.dev/):** Enforced "anti-slop" frontend framework for clean, highly aesthetic UI architecture.
- **GSAP (https://gsap.com/):** Core engine for programmatic 3D component animations.
- **21st.dev (https://21st.dev/):** Aggregation of free and paid UI templates.

**Visual Reference Invariant (Paid Templates):**
If a template on any of these platforms is paid but achieves the target aesthetic, agents/developers MUST NOT ignore it. You are required to use it as a gold-standard reference: screenshot or screen-record the interactive elements and reverse-engineer the aesthetic using TasteSkill and GSAP.
