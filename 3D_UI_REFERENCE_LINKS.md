# 3D UI & Frontend Architecture References
*Note: This is a local project shortcut. The master rule is safely stored in the Obsidian Second Brain (`Self Improvement/Master Self Improvements.md`).*

- **OriginKit:** https://www.originkit.dev/ (Ready-to-use 3D templates)
- **ThreeUI:** https://threeui.com/ (Free 3D templates)
- **TasteSkill:** https://tasteskill.dev/ (Anti-slop frontend framework)
- **GSAP:** https://gsap.com/ (3D animation engine)
- **21st.dev:** https://21st.dev/ (Free & paid reference templates)

**Standard Operating Procedure:**
If a template is paid but fits the required aesthetic, DO NOT discard it. Screenshot or screen-record it and reverse-engineer the design as a reference.
